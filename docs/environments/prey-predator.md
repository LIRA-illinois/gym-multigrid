# Prey-Predator Environment

![Prey Predator Example](/assets/prey-pred-env-example.gif)

## Overview

The Prey-Predator environment is a multi-agent environment where predators chase and capture prey within designated territories. This environment is designed for studying cooperative and competitive multi-agent behaviors, with different prey types requiring different capture strategies.

## Environment Details

| Attribute             | Description                                 |
| --------------------- | ------------------------------------------- |
| Action Space          | `Discrete(5)` (STAY, LEFT, DOWN, RIGHT, UP) |
| Observation Space     | `Box` of shape `(2, width, height)`         |
| Observation Encoding  | See [Observation Details](#observation)     |
| Reward                | Configurable capture rewards per prey type  |
| Number of Agents      | Configurable predators and prey             |
| Termination Condition | All prey are captured                       |
| Truncation Steps      | Configurable (default: 300)                 |
| Creation              | `gymnasium.make("multigrid-prey-pred-v0")`  |

## Observation

The observation is a 3D array of shape `(2, width, height)`:
- **Layer 0**: Static objects (walls, prey territories)
- **Layer 1**: Dynamic objects (predators, prey)

### Encoding
- `0`: empty
- `1`: wall
- `2`: prey_area
- `3`: predator
- `4`: easy_prey
- `5`: hard_prey
- `6`: dead_prey

### Configuration Options

The observation can be configured via `ObservationConfig`:
- `encode_prey_areas`: Whether to encode prey areas in the observation (default: `True`)

## Actions

The environment uses 5 discrete actions:
- `0`: STAY - Agent remains in current position
- `1`: LEFT - Move left
- `2`: DOWN - Move down
- `3`: RIGHT - Move right
- `4`: UP - Move up

**Important**: 
- Predator movements are controlled by the user via `step()`
- Prey movements are automatically generated by the environment using their assigned policies (default: random)

## Agent Types

### Predators

Predators can be configured with different behaviors:

#### Policy Types
- **Ego**: Controlled by the user, can capture any prey
- **Teammate**: Controlled by environment, can only capture designated target prey

#### Configuration
```python
predator_config = {
    "init_pos": (6, 6),               # Initial position
    "policy_type": "ego",             # "ego" or "teammate"
    "color": "red",                   # Visual color
    "target_preys": [],               # List of prey indices to target
}
```

### Prey

Prey have territories and different capture requirements:

#### Prey Types
- **Easy Prey**: Requires 1 predator to capture, immediately fixed
- **Hard Prey**: Requires 2 predators to capture, 1 predator to fix

#### Configuration
```python
prey_config = {
    "type": "easy_prey",              # "easy_prey" or "hard_prey"
    "territory_dims": (4, 4),         # Territory size
    "territory_left_top_corner": (2, 2),  # Territory position
    "color": "yellow",                # Visual color
}

prey_type_config = {
    "name": "easy_prey",
    "policy": "random",               # Movement policy
    "capture_reward": 1.0,            # Reward for capturing
    "num_required_preds_capture": 1,  # Predators needed to capture
    "num_required_preds_fix": 1,      # Predators needed to fix
}
```

## Rewards

Predators receive rewards based on the prey they capture:
- Reward equals the `capture_reward` of the captured prey type
- Default rewards are configurable per prey type
- Easy prey: typically `1.0` reward
- Hard prey: typically `1.0` reward (but requires more coordination)

## Termination

The episode terminates when all prey are captured and fixed.

## Capture Mechanics

### Capture Process
1. **Capture**: Predators move to prey position
   - Easy prey: 1 predator required
   - Hard prey: 2 predators required simultaneously
2. **Fix**: Captured prey must be "fixed" (finalized)
   - Easy prey: 0 additional predators needed (automatic)
   - Hard prey: 1 predator needed

### Territory Constraints
- Prey can only move within their designated territories
- Predators can move anywhere on the grid
- Prey territories are defined by `territory_left_top_corner` and `territory_dims`

## Usage Example

```python
import gymnasium as gym
import gym_multigrid

env = gym.make(
    "multigrid-prey-pred-v0",
    max_episode_steps=100,
    kwargs={
        "observation_config": {
            "encode_prey_areas": True,
        },
        "pred_configs": [
            {
                "init_pos": (6, 6),
                "policy_type": "ego",
                "color": "red",
                "target_preys": [],
            },
            {
                "init_pos": (6, 7),
                "policy_type": "teammate",
                "color": "blue",
                "target_preys": [0],  # Target first prey
            },
        ],
        "prey_configs": [
            {
                "type": "easy_prey",
                "territory_dims": (4, 4),
                "territory_left_top_corner": (2, 2),
                "color": "yellow",
            },
            {
                "type": "hard_prey",
                "territory_dims": (4, 4),
                "territory_left_top_corner": (9, 9),
                "color": "red",
            },
        ],
        "prey_types": [
            {
                "name": "easy_prey",
                "policy": "random",
                "capture_reward": 1.0,
                "num_required_preds_capture": 1,
                "num_required_preds_fix": 1,
            },
            {
                "name": "hard_prey",
                "policy": "random",
                "capture_reward": 1.0,
                "num_required_preds_capture": 2,
                "num_required_preds_fix": 1,
            },
        ],
    },
)

# Reset environment
obs, info = env.reset()

# Take actions (only for ego predators)
predator_actions = [1, 2]  # Actions for ego predators
obs, reward, terminated, truncated, info = env.step(predator_actions)
```

## Advanced Features

### Custom Prey Policies
You can implement custom movement policies for prey by extending the prey policy system.

### Teammate Predator Targeting
Teammate predators can be assigned specific prey to target using the `target_preys` parameter:

```python
predator_config = {
    "init_pos": (7, 7),
    "policy_type": "teammate",
    "color": "blue",
    "target_preys": [0, 2],  # Target prey at indices 0 and 2
}
```

### Cooperative Strategies
Hard prey require coordination between multiple predators, making this environment suitable for studying:
- Multi-agent coordination
- Cooperative capture strategies
- Role allocation among agents

### Rendering

The environment supports standard rendering modes:
- **Human**: Visual rendering showing territories, predators, and prey
- **RGB Array**: Returns environment state as RGB array

```python
# Render as RGB array
rgb_array = env.render()

# Render for human viewing
env.render_mode = "human"
env.render()
```
